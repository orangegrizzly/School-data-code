# Some notes from the data :

-  First, my apologies for ugly looking coding. I am not a clean code. However, I try to document stuff in my code.

 - Second, I avoid setting seeds to avoid messing up RNG (random number generator).  So you will get slightly different values depending on the run of the analysis. 

 - Third, I do occasionally save files and reload them.

 - Fourth, I prefer R because it is free (universal), open, and transparent.

Thank you for taking the time to review my code. We all make errors (e.g., coding). I try to catch them, but still I am happy you decided to help me with a code review! Science is a collective effort and therefore I appreciate a caring and careful peer review. Better to catch errors than publish them (my worst nightmare!). So if you find errors, please let me know!
